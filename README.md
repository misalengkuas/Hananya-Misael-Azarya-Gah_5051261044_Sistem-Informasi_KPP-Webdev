## Isi Halaman
Navbar, Hero, Fitur, Mockup (3 layar utama), ajakan sponsor, dan Footer.

## Struktur File
- `index.html` : struktur halaman (header, nav, main, section, footer)
- `style.css` : seluruh styling
- `assets/` : favicon
- `fonts/` : font Robotica beserta lisensinya

## Catatan
- Dibuat hanya dengan HTML dan CSS, tanpa JavaScript dan framework. Menu di layar HP memakai teknik checkbox CSS.
- Responsif untuk layar laptop dan HP.
- Data pada bagian "Tampilan" hanyalah contoh untuk mockup. Angka anggaran adalah estimasi fase prototipe.
- Font Robotica oleh Darrell Flood, gratis untuk penggunaan pribadi (lihat `fonts/license.txt`). Font Plus Jakarta Sans dari Google Fonts.
